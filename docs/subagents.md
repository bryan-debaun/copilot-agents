# Using Subagents for Independent Research

This document explains when and how to use subagents (the `agent` tool) to perform longer-running or context-heavy research tasks.

## When to use subagents

- Codebase pattern research
- Dependency investigation
- Architecture analysis
- API schema research
- Test pattern analysis

## How to use subagents

1. Identify the research need
2. Craft a focused prompt
3. Invoke the subagent
4. Implement based on findings
